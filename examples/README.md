# Verified first inspection

These small reference artifacts summarize NASA B0005 using `scripts/inspect_sample.py`, verified on 2026-10-17. Capacity values are retained from the source records.

- `B0005-inspection.png`: capacity trend plus first-record voltage and temperature curves.
- `B0005-discharge-summary.csv`: one row for each of 168 discharge operations.
- `B0005-inspection.json`: operation counts, first/last discharge metadata, and source hash.

`B0005-comparison.json` is the additional reference generated by the automated investigation on 2026-10-19. It compares discharge 1 with 168, preserves original operation indices, and records a -28.624% change relative to the first discharge. Comparability remains unresolved.

The source manifest is in `data/manifests/B0005.json`. Raw downloads are excluded from Git. Reproduce the files with:

```powershell
.\.venv-py315\Scripts\python.exe scripts/fetch_sample.py
.\.venv-py315\Scripts\python.exe scripts/inspect_sample.py
.\.venv-py315\Scripts\python.exe -m scripts.run_investigation
```

New runs write to ignored `outputs/`, leaving this reviewed reference snapshot unchanged. Setup instructions are in the [project README](../README.md).

## Verification and interpretation

The reference inspection checked the source and README hashes, reconciled all 616 operations, and matched all 168 exported capacity values to a separate MATLAB-file read using SciPy's object-structure mode. Discharge arrays were checked for finite values, matching lengths, and strictly increasing elapsed times.

The comparison workflow passed 12 tests covering data checks, selection errors, arithmetic, repeat-run identity, and completion-marker removal after output failure. Both comparisons above were checked independently with Decimal arithmetic; real-run output hashes and repeat behavior were verified.

The default pair has recorded ambient metadata of 24 C in both records, but protocol verification and detailed load-profile matching remain unresolved. These results do not establish physical cause or battery end of life. The first discharge record includes readings after the main negative-current portion; its recording duration is not a segmented active-discharge duration.

The PNG shows the full capacity trend and the first source discharge's voltage and temperature traces, regardless of the selected comparison pair.
